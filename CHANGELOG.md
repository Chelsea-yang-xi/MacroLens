# Changelog

## v0.1.0
Initial public version.

### Added
- reusable data loader with schema validation
- monthly return and macro feature engineering
- time-aware train/test split
- baseline Linear Regression
- MAE, RMSE and R² evaluation
- correlation and coefficient outputs
- basic automated tests
- project roadmap

### Current limitations
- demo data is synthetic
- no visualisation layer yet
- only one baseline model
- no hyperparameter tuning or time-series cross-validation
